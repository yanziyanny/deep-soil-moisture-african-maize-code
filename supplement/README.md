# Supplement Figure Reproduction

This directory contains the packaged supplement figure panels and a lightweight copy script.

Run:

```bash
python supplement/run_all_supplement.py --quick
```

Outputs:

- S3 GLEAM SM-VPD coupling figure.
- S4 GLDAS Noah SM-VPD coupling figure.
- S5 GLDAS Noah nonlinear yield-response figure.
- S6 GLDAS Noah yield-sensitivity figure.
- S7 GLDAS Noah SIF attribution figure.
- S8 XGBoost predicted-versus-observed SIF performance figure.
- S9 Shapley R2 decomposition figure.
- S10 hard energy-filtering sensitivity figure.
- `supplement/outputs/supplement_run_report.json`.
